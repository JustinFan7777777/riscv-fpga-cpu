# CPU 数据通路可视化工具 — Bonus 演示指南

> 教学效率工具 | 分值: 4 | 状态: 完成
> 文件: other/cpu_viz/visualizer.html (~900 行, 纯 HTML 单文件)

---

## 一、功能介绍

**是什么：** 一个浏览器内运行的 RISC-V RV32I 单周期 CPU 数据通路可视化工具。从下拉菜单选择一条指令，SVG 数据通路图会逐级点亮该指令经过的组件、数据路径和控制信号。

**给谁用：** 计算机组成原理课程学生。帮助直观理解不同指令类型 (R/I/Load/Store/B/U/J) 的数据通路差异，以及控制信号如何引导数据流动。

**核心创新：** 纯 HTML 单文件，双击即用，无需网络、无需安装。声明式配置——每条指令的通路定义就是一个 JS 对象，新增指令零成本。

---

## 二、功能演示 (对着屏幕讲)

1. **页面全貌:** 左侧是控制面板 (指令下拉菜单 + 控制信号表 + 文字说明)，右侧是 SVG 数据通路全图
2. **默认 ADD 指令:** 打开页面自动选中 ADD，R-type 通路高亮——PC→IMem→Decoder→RegFile→ALU→RegFile (写回)，蓝色取指→紫色译码→橙色执行→绿色写回
3. **切换 LW (Load):** 下拉框切换到 LW，通路变化——增加了 DataMemory 读 + MemtoReg MUX 选通内存数据，MemtoReg=1
4. **切换 BEQ (Branch):** 分支通路——RegWrite=0, Branch=1, 分支比较器激活，Next-PC MUX 切换到分支目标
5. **切换 JAL:** Jump=1, WD3=PC+4, 看得出返回地址的流向
6. **切换 LUI:** ALU_A=0 的特殊通路——为什么 LUI 的 ALU_A 是 0？因为 0+imm=imm

## 三、关键技术

**架构：** 纯 HTML + CSS + SVG + 原生 JavaScript，零依赖。单文件 ~900 行。

**8 大创新点：**

1. **声明式配置** — 每条指令就是一个 JS 对象 `{comps: [...], paths: [...], ctrl: {...}}`，切换指令无 if/else
2. **CSS 类驱动激活** — 所有视觉变化通过切换 CSS 类实现，改配色只需改 CSS 变量
3. **三层颜色架构** — 5 个流水线阶段颜色 (蓝紫橙黄绿) + 7 条控制信号颜色 + 非活跃深灰蓝
4. **主干路径模式** — 多路径汇合处画"主干"再分支，消除视觉缺口
5. **透明度策略** — 非活跃路径 `opacity:0.18`，不遮盖活跃路径，无需动态 DOM 重排
6. **x 坐标自动阶段映射** — getBBox() 获取组件 x 坐标，自动判断属于哪个流水线阶段
7. **6 步渲染流水线** — 清除→文本→信号→阶段→组件→数据路径→控制路径，最小化闪烁
8. **单文件零依赖** — 一个 HTML 包含全部，双击即用，方便分享
