# VGA 文本显示控制器 — Bonus 演示指南

> 复杂外设接口 | 分值: 5 | 状态: 完成
> 文件: VGA.v (~340 行), DataMemory.v (帧缓冲部分), TopDebug.v (VGA 端口)

---

## 一、功能介绍

纯 Verilog 实现的 VGA 文本模式显示控制器。640×480@60Hz, 80 列×30 行, 8×16 像素字符, 支持 16 种前景色×16 种背景色。CPU 通过 MMIO 写入帧缓冲即可在显示器上输出彩色文字。

**显示规格：**
- 分辨率: 640×480@60Hz (25MHz 像素时钟, 100MHz/4)
- 字符网格: 80 列 × 30 行
- 字符大小: 8×16 像素
- 字模: 128 个 ASCII 字符 (其他/vga/font_rom.txt, $readmemh 加载)
- 帧缓冲: 2400×16-bit 双端口 BRAM
- 色彩: 12-bit (I+R+G+B, 每通道 4-bit 输出)

## 二、架构讲解 (画图 or 指代码)

**数据流:**

```
CPU (12.5MHz)                         VGA 控制器 (25MHz)
    │                                       │
    │ sw x1, 0xFFFF0100(x0)                │
    ▼                                       │
DataMemory.v                                │
  ├─ Port A (CPU): 写入 16-bit 帧缓冲       │
  │   MMIO 译码: Addr[31:16]==0xFFFF        │
  │   → 路由到 VGA 帧缓冲 BRAM              │
  │                                         │
  └─ Port B (VGA): 逐像素扫描读出 ──────────▶ VGA.v
                                              ├─ 字模 ROM 查表 (ASCII → 8×16 位图)
                                              ├─ 2 级像素流水线 (预取→BRAM→字模→着色)
                                              └─ vga_hs/vs + vga_r/g/b 输出
```

**VGA 时序参数 (640×480@60Hz, 25MHz):**
- 水平: 640 有效 + 16 前沿 + 96 同步 + 48 后沿 = 800 像素
- 垂直: 480 有效 + 10 前沿 + 2 同步 + 33 后沿 = 525 行

## 三、视频演示流程 (对着屏幕)

**1. 硬件连接展示:**
- 特写 EGO1 VGA 接口 → VGA 线 → 显示器
- "VGA 控制器驱动 14 个引脚——HSYNC, VSYNC, 以及红绿蓝各 4 位共 12 位色彩"

**2. 代码走读 (切换 Vivado):**
- VGA.v: 时序生成部分 (h_cnt/v_cnt 计数器, HS/VS 同步信号生成)
- VGA.v: 字模 ROM 部分 (`$readmemh` 加载 font_rom.txt, 128×16=2048 条目)
- VGA.v: 像素流水线 (fb_addr 预取→char_data 锁存→font_rom 查表→着色)
- DataMemory.v: 帧缓冲双端口 BRAM + MMIO 地址译码

**3. 实际演示 (切回桌面, 运行 Python 测试脚本):**
- 显示器从 "No Signal" → 黑屏
- 串口写入亮绿色 'A' (0x0A41) 到 0xFFFF_0100 → 左上角出现彩色 A
- 写入亮红色 'B' (0x0C42) → 旁边出现红色 B
- 写入白色 '!' (0x0F21) → 白色感叹号
- "三个字符, 三种颜色, 三个位置——全部正确。"

## 五、创新点

1. **纯 Verilog, 零 IP 核** — 时序生成、字模 ROM、像素着色全部手写
2. **双端口 BRAM 软硬件通信** — CPU 12.5MHz 写, VGA 25MHz 读, 完全异步, 零开销
3. **MMIO 统一地址空间** — VGA 帧缓冲与传统外设共用同一套译码器
4. **像素级预取流水线** — fb_addr 提前 5 像素切换, 确保每字符第 0 像素就有正确数据
