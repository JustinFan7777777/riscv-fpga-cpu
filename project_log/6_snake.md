## 一、功能介绍

纯 RISC-V RV32I 汇编实现的贪吃蛇游戏，运行在自研单周期 CPU 上。无操作系统、无库函数、无乘法器。通过 MMIO 读取 EGO1 按键方向，写入 VGA 帧缓冲渲染画面。

**控制方式:**
| 按键 | 功能 |
|------|------|
| btn[0] | 上 |
| btn[1] | 下 |
| btn[2] | 左 |
| btn[3] | 右 |
| btn[4] | 重新开始 |

**画面元素:** `@`=亮绿蛇头, `o`=亮绿蛇身, `*`=亮红食物, `#`=暗灰墙壁

## 二、核心算法 (画白板 or 指代码)

### 2.1 环形缓冲区 (O(1) 蛇身移动)

```
SNAKE_X[512] + SNAKE_Y[512]  环形缓冲区
  HEAD → 最新蛇头位置
  TAIL → 最旧蛇尾位置
  取模: index & 0x1FF (等价于 % 512)

移动一步:
  1. HEAD = (HEAD+1) & 0x1FF
  2. buffer[HEAD] = new_xy
  3. 如果没吃到食物: TAIL = (TAIL+1) & 0x1FF (擦除旧尾)
  4. 如果吃到食物: TAIL 不动, LEN++
```

**为什么是 O(1):** 不需要移动数组元素, 只更新 HEAD/TAIL 索引。

### 2.2 LFSR 伪随机食物

```
16-bit 反馈多项式: x^16 + x^15 + x^14 + x^13 + x^4 + 1
new_bit = lfsr[15] ^ lfsr[14] ^ lfsr[13] ^ lfsr[4] ^ lfsr[0]
lfsr = (lfsr >> 1) | (new_bit << 15)

食物坐标:
  x = (lfsr & 0x7F) % 78 + 1  (范围 1~78)
  y = (lfsr & 0x1F) % 28 + 1  (范围 1~28)
  拒绝采样: 如果坐标在蛇身上 → 重新生成
```

### 2.3 自身碰撞检测

遍历环形缓冲区从 `(HEAD-LEN+1)` 到 `(HEAD-1)`, 跳过 TAIL (即将被擦除), 逐一与新蛇头坐标比对。

### 2.4 VGA 地址计算 (移位替代乘法)

```
row×80 = row×64 + row×16         // slli 6 + slli 4 + add
VGA地址 = 0xFFFF_0100 + 2×(row×80 + col)
```

### 2.5 增量渲染

每帧只重绘 3 个位置:
1. 新蛇头 → 写 `@` (亮绿)
2. 旧蛇头 → 写 `o` (亮绿, 变身体)
3. 旧蛇尾 → 写空格 (擦除)

不清全屏——VGA 帧缓冲 BRAM 的值持久保留。

## 三、视频演示流程

**1. 正常游玩 (10s 连续操作):**
- 上电自动进入游戏
- 按键控制蛇上下左右移动
- 展示游戏流畅度

**2. 吃食物 (特写蛇身变长):**
- 蛇头碰到红色 `*` → 蛇身增长 1 节
- 新食物随机出现在空白位置

**3. 游戏结束 (演示碰撞):**
- 故意撞墙 → 屏幕显示 "GAME OVER"
- 讲解碰撞检测逻辑

**4. 重新开始:**
- 按 btn[4] → 游戏重置
- 蛇回到初始位置, LFSR 重新播种

## 四、Bug 记录

| # | 问题 | 修复 |
|---|------|------|
| 1 | 自身碰撞遍历 `[0..len-1]` 而非环形缓冲区 | 改为从 `(HEAD-LEN+1)` 开始遍历, `& 0x1FF` 取模 |
| 2 | LFSR 缺少 x^0 项 → 周期非最大 (不是完整的 65535) | bit[0] 加入反馈 XOR, commit `c4572f5` |

## 五、创新点

1. **纯汇编游戏** — 416 条 RV32I 指令, 无操作系统, 无库函数
2. **环形缓冲区 O(1) 蛇身移动** — HEAD/TAIL 索引追踪, 不需要移动数组
3. **LFSR 硬件友好随机数** — 仅用移位和 XOR, 无需乘法/除法
4. **增量渲染** — 每帧 3 次写入, 利用 BRAM 持久化特性
5. **移位替代乘法** — `row×80 = row×64 + row×16`, RV32I 无 MUL
