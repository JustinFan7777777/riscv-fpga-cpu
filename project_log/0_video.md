| # | 内容 | 分值 | 时长建议 |

```

旁白: "首先验证VGA基础显示。工程包含12个Verilog模块，顶层TopDebug，

关键展示：

```

### 镜头 5：技术亮点（~40s）

```
画面: 代码特写 + 架构图交替
旁白: "三个核心技术亮点。第一，MMIO内存映射I/O——CPU通过sw指令直接写
       0xFFFF0100地址，硬件译码器将写入操作路由到VGA帧缓冲BRAM，
       CPU不需要知道VGA的存在。第二，双端口BRAM——CPU在12.5MHz时钟域
       写入帧缓冲，VGA在25MHz时钟域独立读出，两个系统完全异步但共享
       同一块物理内存。第三，增量渲染——帧缓冲是持久化的，蛇每帧只需
       重绘3个变化的位置，不用清屏重绘全部2400个字符。"
```

## 三、录制前检查清单

### 硬件

- [ ] EGO1 板子正常（上电 LED 亮）
- [ ] VGA 显示器正常（先不开 EGO1，确认显示器本身能显示 "No Signal"）
- [ ] VGA 线完好（两头插紧，无松动）
- [ ] Micro-USB 线完好（能烧录 + 串口通信正常）
- [ ] 5 个按键均可正常按下回弹

### 软件

- [ ] Vivado 工程可正常综合（无报错）
- [ ] Bitstream 已生成（`TopDebug.bit` 在 `impl_1/` 下）
- [ ] `bonus-vga-snake` 分支为最新：`git pull origin bonus-vga-snake`
- [ ] `snake.hex` 已编译（416 条指令）
- [ ] Ifetch.v 已改为 `PC_RESET = 0` + `INIT_FILE` 指向 snake.hex

### 环境

- [ ] 三人均在现场（录制全程需要至少一人操作、一人讲解、一人确认）
- [ ] 桌面整洁（只留必需设备，避免杂物入镜）
- [ ] 光线充足（不要逆光，确保板子和显示器清晰可见）
- [ ] 录制设备（手机/相机）支架固定，画面稳定
- [ ] 测试一遍完整流程后再正式录制
